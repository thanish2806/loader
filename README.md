# Loader Animation by Thanish

A clean and modern **loader animation** built using HTML, CSS, and JavaScript. This loader uses moving circles to create a smooth, visually appealing animation while a page or application is loading.

---

## 🔹 Features

- Minimal and responsive design
- Smooth motion-circle animation
- Customizable colors and speed
- Lightweight and easy to integrate into any project
- Works on both desktop and mobile
